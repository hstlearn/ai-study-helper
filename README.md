# AI 학습 도우미 (AI Study Helper)

## 项目简介
面向在韩外国考生的 AI 备考助手。上传韩语教材/真题截图，自动生成翻译 + 术语解释 + 考点讲解的 Markdown 学习笔记。

## 技术栈
- Gemini API (多模态识别 + 翻译 + 讲解)
- Gradio (界面)
- Hugging Face Spaces (部署)

## 在线体验
https://huggingface.co/spaces/mlgbwcnm/ai-study-helper

## 本地运行
pip install -r requirements.txt
python app.py
